# Pitch Deck

_Отдел: 05 Финансы_

## Процесс

1. 10–12 слайдов: проблема, решение, почему сейчас, рынок (TAM/SAM/SOM), продукт, трэкшн, бизнес-модель, конкуренты, GTM, команда, финансы, ask.
2. Заголовок каждого слайда — утверждение.
3. Цифры с источниками; трэкшн графиком.
4. Ask: сумма, на что, какие вехи достигнем.
5. Оформление — см. навык pitch-visuals.

## Результат

Структура и тексты слайдов (+ .pptx при запросе).

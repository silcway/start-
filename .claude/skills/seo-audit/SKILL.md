# SEO Audit

_Отдел: 03 Маркетинг_

## Процесс

1. Техника: индексируемость (robots.txt, meta robots, canonical), sitemap.xml, коды ответа, редиректы, скорость (Core Web Vitals), мобильность, HTTPS.
2. On-page: title (≤60), description (≤155), один H1, структура H2–H3, alt у картинок, внутренние ссылки, schema.org.
3. Контент: соответствие интенту запроса, уникальность, полнота, E-E-A-T.
4. Ключи: основной + LSI, каннибализация между страницами.
5. Приоритизируй по влияние × усилие.

## Результат

Отчёт: проблема → где → фикс → приоритет.

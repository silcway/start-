# Automation

_Отдел: 06 Операции_

## Процесс

1. Опиши процесс как триггер → шаги → результат; посчитай экономию времени.
2. Выбери инструмент: no-code (n8n/Make/Zapier) или скрипт + cron/GitHub Actions.
3. Идемпотентность, ретраи, логирование, уведомление при ошибке.
4. Секреты — в переменных окружения/хранилище.
5. Тест на реальных данных в песочнице.

## Результат

Схема автоматизации + код/конфиг + инструкция запуска.

# Canvas

_Отдел: 02 Дизайн_

## Процесс

1. Сформулируй визуальную идею одним предложением (настроение, метафора).
2. Задай формат (1080×1080, 1080×1350, 1920×1080, A4) и сетку.
3. Рисуй в SVG или через Python (Pillow/matplotlib) / HTML canvas; текст — минимум, крупно.
4. Композиция: один фокус, контраст масштаба, воздух.
5. Экспорт в PNG @2x; проверь читаемость на мобильном.

## Результат

SVG/PNG файл + исходник.

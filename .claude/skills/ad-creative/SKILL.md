# Ad Creative

_Отдел: 03 Маркетинг_

## Процесс

1. Определи аудиторию, боль, оффер, площадку и её лимиты символов.
2. Сделай 5+ углов: боль, выгода, соцдоказательство, срочность, сравнение, любопытство.
3. Для каждого: хук (первые 3 секунды/строка), тело, CTA.
4. Опиши визуал/сценарий видео.
5. Предложи план A/B-теста (одна переменная за раз).

## Результат

Таблица вариантов креативов + гипотезы теста.

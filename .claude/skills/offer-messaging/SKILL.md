# Offer Messaging

_Отдел: 03 Маркетинг_

## Процесс

1. Сегмент → работа, которую клиент «нанимает» продукт выполнить (JTBD).
2. Альтернативы клиента и чем мы отличаемся.
3. Ценностное предложение: результат + срок + без чего (риск/усилие).
4. Усилители оффера: бонусы, гарантия, ограничение, рассрочка.
5. Сделай 3 версии заголовка: рациональная, эмоциональная, провокационная.

## Результат

Позиционирование, формула оффера, заголовки и буллеты.

# Programmatic SEO

_Отдел: 03 Маркетинг_

## Процесс

1. Найди паттерн запросов «[сущность] + [модификатор]» (город, сравнение, интеграция).
2. Собери датасет сущностей; проверь спрос и уникальную ценность каждой страницы.
3. Спроектируй шаблон: уникальные блоки из данных, а не подмена слов.
4. URL-структура, внутренняя перелинковка, sitemap.
5. Контроль качества: минимум уникального контента, noindex для тонких страниц.

## Результат

Шаблон страницы, схема данных, скрипт генерации, план перелинковки.

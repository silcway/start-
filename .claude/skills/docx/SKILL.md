# DOCX

_Отдел: 07 Legal + Security_

## Процесс

1. Используй python-docx (или docx-js); стили заголовков, а не ручной жирный.
2. Нумерация пунктов, колонтитулы, номера страниц, таблицы со стилем.
3. При правке существующего — сохраняй форматирование, не пересоздавай документ.
4. Проверь результат конвертацией в PDF/текст.

## Результат

.docx файл.

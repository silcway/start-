# Sales Model

_Отдел: 05 Финансы_

## Процесс

1. Воронка: лиды → квалифицированные → встречи → предложения → сделки; конверсии и цикл сделки.
2. Средний чек, план выручки → нужное число сделок → лидов.
3. Ёмкость менеджера (сделок/мес.), ramp-up; сколько нанять.
4. Каналы лидогенерации и стоимость лида.
5. Сценарии и узкие места.

# Strategy

_Отдел: 04 Контент_

## Процесс

1. Цель бизнеса → роль контента (узнаваемость, доверие, продажи).
2. Аудитория: сегменты, боли, вопросы, где она живёт.
3. Рубрики (3–6) с долями: польза / экспертиза / личное / продажи.
4. Форматы по площадкам и частота.
5. Календарь на 4 недели: дата, площадка, рубрика, тема, формат, CTA.
6. Метрики и ритм пересмотра.

## Результат

Документ стратегии + таблица календаря.

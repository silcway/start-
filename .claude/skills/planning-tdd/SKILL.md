# Planning + TDD

_Отдел: 01 Разработка_

## Процесс

1. Уточни цель фичи, критерии приёмки и границы (что НЕ входит).
2. Изучи код: найди точки входа, похожие модули, существующие тесты и тест-раннер.
3. Составь план из маленьких шагов; каждый шаг = одно проверяемое поведение.
4. Для каждого шага: напиши падающий тест (RED) → запусти и убедись, что падает по правильной причине.
5. Напиши минимальный код, чтобы тест прошёл (GREEN) → запусти все тесты.
6. Рефактори без изменения поведения (REFACTOR) → тесты снова зелёные.
7. Не пропускай и не отключай тесты ради зелёного прогона.

## Результат

План шагов, список добавленных тестов, вывод тест-раннера.

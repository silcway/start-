# Pillar Content

_Отдел: 04 Контент_

## Процесс

1. Выбери ядро-тему с высоким спросом; собери кластер подтем.
2. Напиши опорный материал: структура H2/H3, примеры, FAQ.
3. Разбей на производные: посты, карусели, шортсы, email, треды.
4. Свяжи перелинковкой: производные ведут на pillar.

## Результат

Pillar-материал + список производных единиц с текстами.

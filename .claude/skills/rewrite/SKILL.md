# Rewrite

_Отдел: 04 Контент_

## Процесс

1. Сохрани смысл и факты; не добавляй выдуманного.
2. Убери воду, канцелярит, пассив, повторы.
3. Подстрой тон под задачу (деловой, дружеский, продающий).
4. Короткие предложения, активные глаголы, конкретика.
5. Покажи итог и (если просят) ключевые изменения.

## Результат

Переписанный текст.

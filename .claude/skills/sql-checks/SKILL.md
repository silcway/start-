# SQL Checks

_Отдел: 07 Legal + Security_

## Процесс

1. Безопасность: только параметризованные запросы, нет конкатенации пользовательского ввода, минимальные права.
2. Корректность: JOIN-условия, NULL-семантика, GROUP BY, дубли, часовые пояса.
3. Производительность: EXPLAIN, индексы, N+1, SELECT *, пагинация через keyset.
4. Миграции: обратимость, блокировки на больших таблицах.
5. Проверки качества данных: уникальность, ссылочная целостность, пропуски.

## Результат

Список проблем + исправленный SQL.

# Forecast

_Отдел: 05 Финансы_

## Процесс

1. Модель от драйверов: трафик → лиды → клиенты → выручка, плюс churn.
2. Расходы: фикс и переменные, найм, разовые.
3. Помесячно на 12–24 мес.; кэш на счёте и точка безубыточности.
4. Три сценария: пессимистичный / базовый / оптимистичный.
5. Все допущения на отдельном листе.

## Результат

Финмодель .xlsx с листами Допущения / Прогноз / Сценарии.

# SOP

_Отдел: 06 Операции_

## Процесс

1. Цель процесса, владелец, триггер старта, результат.
2. Пошагово: кто → что делает → в каком инструменте → критерий готовности.
3. Развилки и исключения; что делать при ошибке.
4. Чек-лист для исполнителя; сроки/SLA.
5. Версия и дата пересмотра.

## Результат

Документ SOP (Markdown/DOCX) + чек-лист.

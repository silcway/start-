# Landing Audit

_Отдел: 03 Маркетинг_

## Процесс

1. 5-секундный тест: понятно ли что, для кого, почему сейчас.
2. Первый экран: заголовок-выгода, подзаголовок, CTA, визуал продукта.
3. Доверие: отзывы, логотипы, цифры, гарантии.
4. Возражения закрыты (FAQ, цена, риски).
5. Трение: длина форм, скорость загрузки, мобильная версия.
6. Один главный CTA, повторяется по странице.

## Результат

Список проблем по блокам + переписанный первый экран.

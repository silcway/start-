# Pitch Visuals

_Отдел: 02 Дизайн_

## Процесс

1. Одна мысль на слайд; заголовок = вывод, а не тема.
2. Структура: проблема → решение → рынок → продукт → трэкшн → модель → команда → ask.
3. Графики вместо таблиц; выделяй одну цифру акцентным цветом.
4. Единая сетка, 2 шрифта, 3–4 цвета.
5. Для .pptx используй python-pptx; для веба — HTML-слайды.

## Результат

Слайды (.pptx/.html) + тезисы спикера.

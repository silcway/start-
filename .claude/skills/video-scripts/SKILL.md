# Video Scripts

_Отдел: 04 Контент_

## Процесс

1. Длительность и площадка; одна идея на ролик.
2. Хук 0–3 c (визуальный + словесный), затем удержание: открытые петли, смена плана каждые 2–4 c.
3. Структура: хук → проблема → ценность/история → payoff → CTA.
4. Формат таблицы: время | кадр/визуал | текст в кадре | закадр.
5. Дай 3 варианта хука и заголовок/обложку.

## Результат

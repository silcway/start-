# Release Check

_Отдел: 01 Разработка_

## Процесс

1. Сборка: чистая установка зависимостей и build проходят без ошибок.
2. Тесты: юнит + интеграционные + e2e зелёные; линтер и типы без ошибок.
3. Безопасность: нет секретов в коде (git grep), уязвимости зависимостей (npm audit / pip-audit).
4. Миграции БД обратимы и протестированы; есть план отката.
5. Версия, CHANGELOG, переменные окружения задокументированы.
6. Мониторинг/алерты для новых фич; feature-флаги для рискованных изменений.

## Результат

Чек-лист с ✅/❌ по каждому пункту и вердикт GO / NO-GO с блокерами.

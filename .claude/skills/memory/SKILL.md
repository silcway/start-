# Memory

_Отдел: 01 Разработка_

## Процесс

1. Храни долгосрочный контекст в CLAUDE.md (кратко: стек, команды, конвенции, запреты).
2. Решения — в docs/decisions/NNNN-title.md (ADR: контекст, решение, последствия).
3. Перед записью проверь, нет ли дубля; обновляй, а не дописывай противоречия.
4. Пиши факты, а не историю сессии; без секретов и персональных данных.
5. В начале задачи читай CLAUDE.md и релевантные ADR.

## Результат

Обновлённый CLAUDE.md / ADR и краткий список изменений.

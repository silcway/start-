# CRM

_Отдел: 06 Операции_

## Процесс

1. Сущности: контакты, компании, сделки, задачи; обязательные поля.
2. Этапы воронки с критериями входа/выхода.
3. Правила: следующий шаг у каждой сделки, сроки, ответственный.
4. Автоматизации: задачи при смене этапа, напоминания.
5. Аудит гигиены: дубли, сделки без активности > N дней, пустые поля.

## Результат

Схема CRM + список правил и автоматизаций / отчёт аудита.

# Social Copywriting

_Отдел: 04 Контент_

## Процесс

1. Определи площадку, цель (охват/вовлечение/продажа) и голос автора.
2. Хук в первой строке: цифра, противоречие, вопрос, обещание.
3. Тело: короткие абзацы, один пост = одна мысль, конкретика и примеры.
4. CTA: комментарий-кодовое слово, сохранить, подписаться, ссылка.
5. Для каруселей — текст по слайдам (≤ 25 слов на слайд).
6. Дай 3 варианта хука.

## Результат

Готовый текст поста + варианты хуков + хештеги при необходимости.

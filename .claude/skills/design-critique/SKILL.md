# Design Critique

_Отдел: 02 Дизайн_

## Процесс

1. Пойми цель экрана и аудиторию.
2. Оцени: иерархия, читаемость, консистентность, отступы, цвет/контраст, состояния, доступность, адаптив.
3. Для каждой проблемы: что не так → почему это мешает пользователю → конкретный фикс.
4. Отметь, что работает хорошо.
5. Приоритизируй: критично / важно / полировка.

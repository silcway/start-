# Contract Review

_Отдел: 07 Legal + Security_

## Процесс

1. Определи сторону, на которой мы, и тип договора.
2. Ключевые условия: предмет, цена/оплата, сроки, ответственность и её лимит, неустойки, IP, конфиденциальность, расторжение, автопролонгация, применимое право, споры.
3. Флаги: односторонние права, неограниченная ответственность, скрытые платежи, эксклюзивность.
4. Для каждого риска — предложенная формулировка правки.
5. Это не юридическая консультация; для значимых решений привлекай юриста своей юрисдикции.

## Результат

Таблица: пункт → риск (высокий/средний/низкий) → правка.

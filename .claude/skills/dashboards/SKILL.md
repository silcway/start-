# Dashboards

_Отдел: 06 Операции_

## Процесс

1. Для кого и какие решения принимаются по дашборду.
2. 5–8 ключевых метрик; north star сверху.
3. Каждая метрика: определение, источник, период, сравнение с прошлым/целью.
4. Правильный график: тренд — линия, сравнение — бары, доля — stacked bar.
5. Фильтры по периоду/сегменту; без лишнего декора.

## Результат

HTML-дашборд или спецификация метрик.

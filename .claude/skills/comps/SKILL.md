# Comps

_Отдел: 05 Финансы_

## Процесс

1. Отбери 5–10 сравнимых компаний (модель, рынок, стадия).
2. Сравни: продукт, цены, позиционирование, каналы, сильные/слабые стороны.
3. Финансовые comps: выручка, рост, маржа, мультипликаторы (EV/Revenue).
4. Указывай источник и дату каждой цифры; не выдумывай.
5. Вывод: где ниша и преимущество.

## Результат

Сравнительная таблица + выводы.

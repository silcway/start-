# CRO

_Отдел: 03 Маркетинг_

## Процесс

1. Разложи воронку по шагам с конверсией каждого шага; найди самую большую утечку.
2. Собери качественные данные: записи сессий, опросы, отказы.
3. Гипотезы в формате: «Если [изменение], то [метрика] вырастет, потому что [причина]».
4. Приоритизируй ICE (Impact, Confidence, Ease).
5. Рассчитай размер выборки и длительность теста; одна переменная за тест.

## Результат

Карта воронки, бэклог гипотез с ICE, план тестов.

# Ops Backbone

_Отдел: 06 Операции_

## Процесс

1. Карта ключевых процессов (привлечение → продажа → исполнение → поддержка → финансы).
2. Владелец каждого процесса (RACI).
3. Стек инструментов и потоки данных между ними.
4. Ритм управления: дейли/виклы, метрики, ретро.
5. Узкие места и план улучшений на 30/60/90 дней.

## Результат

Документ операционной модели.

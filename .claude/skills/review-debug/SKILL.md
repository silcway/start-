# Review + Debug

_Отдел: 01 Разработка_

## Процесс

1. Ревью: получи diff (git diff / ветка / PR), прочитай изменённые файлы целиком, а не только хунки.
2. Ищи: логические ошибки, граничные случаи (null, пусто, переполнение), гонки, утечки ресурсов, ошибки обработки исключений, безопасность (инъекции, секреты).
3. Каждую находку подтверди: конкретный вход → неверный результат. Неподтверждённое помечай как «возможно».
4. Дебаг: воспроизведи ошибку минимальным примером ДО правок.
5. Сформулируй гипотезы, проверяй по одной (логи, точки останова, бисекция git bisect).
6. Найди корневую причину, а не симптом; добавь регрессионный тест; исправь; прогони тесты.

## Результат

Список находок по критичности (файл:строка, сценарий сбоя, фикс) или отчёт о причине бага.

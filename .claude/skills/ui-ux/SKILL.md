# UI/UX

_Отдел: 02 Дизайн_

## Процесс

1. Определи пользователя, главную задачу экрана и одно ключевое действие.
2. Выбери характер: типографика (1–2 шрифта, выраженная шкала), палитра (нейтрали + 1 акцент), сетка и ритм отступов (4/8px).
3. Избегай шаблонности: не дефолтный Inter+фиолетовый градиент; добавь одну запоминающуюся деталь.
4. Иерархия: размер/вес/цвет указывают порядок чтения; одна primary-кнопка на экран.
5. Состояния: пустое, загрузка, ошибка, успех; hover/focus/disabled.
6. Доступность: контраст ≥ 4.5:1, фокус виден, тач-цели ≥ 44px; адаптив от 360px; тёмная тема.

## Результат

Код компонента/страницы или спецификация экрана с токенами.

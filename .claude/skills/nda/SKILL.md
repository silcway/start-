# NDA

_Отдел: 07 Legal + Security_

## Процесс

1. Тип: односторонний или взаимный.
2. Проверь: определение конфиденциальной информации, исключения, срок, цель использования, возврат/уничтожение, non-solicit, ответственность.
3. Флаги: бессрочность, слишком широкое определение, скрытый non-compete.
4. Вердикт: подписывать / правки / эскалация.
5. Это не юридическая консультация; для значимых решений привлекай юриста своей юрисдикции.

## Результат

Вердикт + список правок или черновик NDA.
